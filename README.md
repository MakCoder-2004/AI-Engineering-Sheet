# AI Engineering Study Guide

Study notes organized from the 2026 AI Engineer roadmap in `00.Roadmap/ai-engineer-roadmap.html`.

## Study Path

The repository is organized as one top-level folder per roadmap topic. Each topic folder contains the Markdown notes and assets for that topic.

## Folder Structure

```text
AI Engineering/
  00.Roadmap/        - Source roadmap files
  00.Prerequisites/  - Phase 0
  01.Transformer_Foundations/
  02.Prompt_Engineering/
  03.Embeddings/
  04.Vector_Databases/
  05.RAG/
  ...
```
