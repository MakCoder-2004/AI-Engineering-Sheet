# Phase 8 — AI Agents and the Agent Harness

This phase covers the concepts and engineering practices behind agents: the control loop, the harness around a model, tools, context and memory, planning, workflows, durability, approvals, evaluation, safety, and production operations.

## Handbook

- **[AI Agents and the Agent Harness](AI_Agents_and_Agent_Harness.md)** — a Python-first, systems-oriented handbook that starts with concepts and a framework-independent harness before surveying frameworks.

## Recommended reading path

1. Start with the distinction between model calls, workflows, agents, and harnesses.
2. Study tool boundaries, the agent loop, and context/memory.
3. Continue through planning, orchestration, persistence, and multi-agent patterns.
4. Read the safety, evaluation, and production sections before building an agent with real data or side effects.
5. Complete the build-along and project exercises.
